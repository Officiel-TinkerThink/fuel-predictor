# 01 — Create a local daily-operation planning foundation

**What to build:** A locally runnable Indonesian form and API that let a planner create one Daily Operation with ANGBER category, activity mode, lifting hours when applicable, a total distance, and a generated operation ID.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] A planner can submit a valid Daily Operation and receive its generated operation ID.
- [ ] Invalid or missing core values are rejected with understandable Indonesian validation feedback.
- [ ] A submitted operation preserves its vehicle category, activity mode, distance, lifting-hours meaning, and source of distance.
- [ ] The locally run form and API expose the same externally observable operation-creation behavior.
